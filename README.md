# Природничі науки: Земля — лекції для самостійного опрацювання

Сайт для студентів: лекції розбиті на блоки, після кожного блоку — питання без доступу до тексту.
Прогрес зберігається після кожного кроку, тож тему можна проходити частинами (тривоги, відключення світла).

## Структура

```
index.html            сторінка студента (карта курсу і проходження теми)
teacher.html          кабінет викладача (доступ до тем, результати, експорт)
course.json           програма курсу: розділи і теми
topics/t09/           тема 9: topic.json (лекція і питання) + img/ (малюнки)
js/firebase-config.js налаштування Firebase і пошта викладача
firestore.rules       правила доступу до бази
```

Ключі відповідей (`tXX_keys.json`) у репозиторій **не кладемо** — вони завантажуються
в кабінеті викладача (вкладка «Ключі відповідей») і зберігаються у Firebase, доступні лише викладачу.

## Перше налаштування (один раз)

1. **GitHub.** Створіть новий репозиторій, завантажте в нього всі файли цієї папки
   (Add file → Upload files). Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
2. **Firebase.** console.firebase.google.com → Add project (новий, окремий від kontrol-znan).
   - Build → Firestore Database → Create database (регіон `europe-west`, production mode).
   - Build → Authentication → Get started → увімкніть **Anonymous** і **Google**.
   - Authentication → Settings → Authorized domains → додайте `ВАШ-ЛОГІН.github.io`.
   - Project settings → Your apps → Web (`</>`) → скопіюйте `firebaseConfig`.
3. Вставте `firebaseConfig` і свою пошту в `js/firebase-config.js`.
4. Відкрийте `firestore.rules`, замініть `ВАША_ПОШТА@gmail.com` на свою пошту,
   скопіюйте весь текст у Firestore → Rules → Publish.
5. Відкрийте `https://ВАШ-ЛОГІН.github.io/РЕПОЗИТОРІЙ/teacher.html`, увійдіть через Google,
   додайте групи, відкрийте тему, завантажте ключі.

Поки `firebaseConfig` не вставлено, сайт працює в **демо-режимі** (усе зберігається лише в браузері) —
так можна все переглянути до підключення Firebase.

## Додавання нової теми

1. Покладіть папку `topics/tXX/` у репозиторій (Add file → Upload files).
2. У кабінеті викладача тема стане доступною: відкрийте її для груп і завантажте `tXX_keys.json`.

## Перевірка відкритих відповідей

Результати → оберіть тему і групу → **JSON (для перевірки відкритих)**. Цей файл можна віддати Claude:
у ньому є питання, відповіді студентів і підсумок блоку лекції, щоб перевіряти за змістом.

## Ігровий компонент

- **Кодове слово.** У тексті кожного блоку сховано букву ✦. Студент вписує її на початку питань блоку.
  Наприкінці з 12 букв (перемішаних) він складає термін теми і пояснює його значення.
  Для теми є 10 різних слів — кожен студент отримує випадкове, тож готову відповідь у чаті групи не перешлеш.
- **Кросворд.** Після 12-го блоку — кросворд із 11–12 термінів теми, 5 варіантів (кожному студенту випадковий).
  Перевірка миттєва: правильні слова зеленіють. Відповіді в коді сайту зашифровані.
- У кабінеті викладача видно: скільки букв знайдено правильно, чи складено слово, скільки слів кросворду розгадано.
